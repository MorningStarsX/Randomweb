## 如何使用

### [1]Fork项目

#### 1.替换默认名单
- 文件路径
   ```
   web/index.html
   ```
   查找
   ```
   const DEFAULT_LIST = {.....}
   ```
   替换.
 >Fork前给个Star吧

#### 2.Push Pages
- 在`Actons`---`Deploy Static Web to GitHub Pages`中选择`Run workflow`
>请确保您Github中的Pages功能开启

### [2]下载HTML文件本地运行
- 文件路径
   ```
   web/index.html
   ```
   进入该文件点击下载按钮
- 按照`替换默认名单`步骤进行
